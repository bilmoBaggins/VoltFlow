# Dev Tools — VS Code + Claude Code

VoltFlow internship standard editor stack.

| Tool | Purpose |
| :--- | :--- |
| **VS Code** | Write / view code, Git UI, terminal |
| **Claude Code** | AI pair programmer inside VS Code (vibe coding) |
| **Git + GitHub** | Branches, PRs, reviews |
| **Postman** | API testing (from Week 1–2) |

## Session 1 install order

1. VS Code — https://code.visualstudio.com/  
2. Git  
3. Claude Code in VS Code + sign-in  
4. Clone repo → Open Folder in VS Code  
5. Open Claude Code → ask it to explain the README  

## Rules for beginners

- Review every Claude Code diff before accepting  
- Never paste secrets / API keys into Claude  
- Small prompts (“add one heading”) beat “build the whole app”  
- You still own the PR — Claude is a helper, not the author of record alone
